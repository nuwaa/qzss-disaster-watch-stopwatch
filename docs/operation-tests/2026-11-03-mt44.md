# 2026年11月3日 MT44公式試験配信の運用試験

## 試験の概要

2026年11月3日（火）13:00～15:00 JSTの[みちびき災危通報（拡張）試験用データ配信](https://qzss.go.jp/technical/dod/dc-report/dcx-test-data-distribution.html)を、M5Stack StopWatch v1.0.1とPRIORIS GR-M10-C/Sで受信した。StopWatchは給電付きUSB-Cアダプタ経由でGNSS受信機に直接接続した。PCは試験中の受信経路に含めず、試験後のログ書き出しと分析に使用した。

本レポートは装置の**運用試験**を記録する。構築手順は[公式試験の準備手順](../official-mt44-test-20261103.md)にある。この端末は研究・実験用であり、認証済みの防災製品ではない。

## 実施と確認方法

1. 試験当日午前、前回までのログをPCに保存してから端末の検証記録領域を消去した。午前の書き出しは679,756バイト、MT43 1,612件、MT44空メッセージ1,511件、JSON行エラー0件だった。
2. 記録用ファームウェアを再書き込みしてGNSSへ接続した。ユーザーが試験前に「L1S受信中」「自動通知待機」と、受信B・L1S・検証記録件数の増加を確認した。
3. 15時過ぎに書き出し専用ファームウェアへ切り替え、`--clear-after-export`を**付けずに**端末のログをPCへ保存した。端末内のログは消去していない。
4. 保存されたSFRBXをAzarashiで再復号し、MT44の種別・A1試験区分・提供元・対象地域・時刻を集計した。結果のExcel/CSVはローカルの`outputs/`に作成し、公開リポジトリには追加していない。

## 画面表示と通知

ユーザーの実機観察では、試験情報が「訓練・試験」として表示され、**試験情報に対する音・振動はなかった**。同じ試験中、地震に関する情報を受信した際には音・振動があったと報告された。

保存ログにも、試験情報とは別に、MT43の優先区分・発表（訓練ではない）に該当する**震源情報**が1種類、417回記録されていた。内容は14:40頃発生、千葉県北東部、M4.7、深さ50km、津波の心配なしという通報で、発表時刻は14:43、最初の記録時刻は14:43:31 JSTだった。これは地震発生後の震源情報であり、緊急地震速報ではない。保存ログは音・振動の発生時刻そのものを記録していないため、その通知がどのメッセージに対応したかはログだけでは確定できない。端末の表示と通知の観察はユーザー報告に基づく。

## 到達点と限界

- 公式資料にある**異なる試験パターンは全シナリオで少なくとも1回受信**した。MT43の受信・表示も継続した。
- 繰り返し送信された各回まで、欠けなく受信したとは言えない。Lアラート前半では60パターンのうち5パターン、Jアラート関係省庁分では24パターンのうち2パターンが、保存ログでは1回だけだった。端末の受信漏れか、配信側の遅延・欠落かは、このログだけでは区別できない。公式も実通報を優先し、試験データの一部が配信されない場合があると案内している。[公式案内](https://qzss.go.jp/technical/dod/dc-report/dcx-test-data-distribution.html)
- 記録対象はCRCが正常なMT43/44である。したがって、このログからRFレベルでの全フレーム受信率やCRC失敗数は算出できない。画面の16件履歴にも全415受信を保持する設計ではない。
- Azarashiの日本語全文は一部文字化けがある。Excel/CSVには読める日本語の対象地域などと、英語全文・構造化フィールドを収録した。
