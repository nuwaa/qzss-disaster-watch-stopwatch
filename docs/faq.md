# よくある質問

現在のPCなし単体版（`firmware/stopwatch-standalone/`）の表示と通知について、実装に基づいて説明します。研究・実験用の端末です。避難判断には公的な情報を確認してください。

## 画面の「古い通報」は、どのくらい古い情報ですか？

タイプ43（DCR）では、GNSS時刻と通報の**発表時刻**を比べ、発表から **15分（900秒）を超える**と「古い通報」と表示します。15分以内は「発表から○分」と表示します。これは画面上の鮮度表示であり、通報そのものの有効期限を示すものではありません。

タイプ44（DCX）では基準時刻が異なります。A6/A7の**災害発生時刻**から15分を超えると「発生から15分超」と表示します。A6/A7は発表時刻ではありません。発生予定が3分より先なら「発生予定時刻は先」と表示します。

GNSS時刻を確認できないときは古さを判定せず、「GNSS時刻未確認」などと表示します。

## 「古い通報」と表示されるまで、音と振動が鳴るのですか？

いいえ。**画面表示の15分と、自動通知の3分は別の基準**です。タイプ43の自動通知は発表から0～180秒、タイプ44は災害発生予定の180秒前から発生後180秒までが時刻上の候補です。この範囲を過ぎても15分以内なら、画面には経過分数が表示されますが、古さの条件だけで見ても新規の自動通知はしません。

時刻以外にも、通報区分・発表または更新の別・重複・時刻の安定性などの条件があります。詳しくは[単体版の自動通知条件](notification-policy.md)を参照してください。
