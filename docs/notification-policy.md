# 単体版の自動通知条件

2026年11月1日時点の `firmware/stopwatch-standalone/src/main.cpp` に実装されている条件です。USB-CホストでGR-M10-C/Sから受信する単体版を対象にします。研究・実験用であり、避難判断は公的な情報で行ってください。11月3日の公式試験前には実災害のタイプ44新着通報による自動通知を確認できていません。

## 共通条件

UBXの整合性とL1SのCRCを通り、対応するタイプ43または44として復号された情報を対象にします。自動通知には有効なGNSS時刻が必要です。端末はチェックサム・測位有効フラグが正しいRMCを連続して受け、最新のRMCから10秒以内を有効時刻として扱います。時刻が安定してから最初の60秒は音・振動を出しません。

同一IDの繰り返し受信は新規通報として扱いません。DCXのIDでは衛星識別とCRCを除外し、別衛星からの同内容の再送も抑制します。画面履歴は16件、通知済みIDはNVSの64件の循環領域に保存します。保存領域が使えない場合は自動通知を止め、「保存不可・通知無効」と表示します。64件を超える古いIDの永続的な重複抑制は保証しません。

## タイプ43：従来の災危通報（DCR）

通報区分が1～3で、情報種別が「発表」（0）の、履歴にない情報が候補です。GNSS時刻と通報の**発表時刻**を比較し、発表から0～180秒以内であれば自動通知します。緊急地震速報だけでなく、条件を満たす他のDCR種別も対象です。通報種別ごとの重大度や端末の所在地では絞っていません。

訓練・試験（通報区分7）、訂正、取消、未来の発表、発表から3分超の情報、時刻が確認できない情報では自動通知しません。準備中に届いた発表のIDも保存するため、準備終了後の再送で新着通知になりません。

## タイプ44：災危通報（拡張）（DCX）

内容のあるDCXで、A1が「発表」（1）または「更新」（2）の、履歴にない情報が候補です。国・地域コードが日本（111）で、Jアラート、Lアラート、自治体通報のいずれかとして復号された場合に限ります。GNSS時刻とA6/A7の**災害発生時刻**を比較し、発生予定の180秒前から発生後180秒までを通知対象とします。A6/A7は発表時刻ではありません。

A1=0の試験、A1=3の全解除、空メッセージ、古い情報、時刻が確認できない情報では自動通知しません。危険種別・重大度・端末所在地と対象地域の一致による絞り込みは実装していません。「日本の情報」という判定も国・地域コードとメッセージ種別によるもので、個別の提供元IDを許可リストで照合してはいません。そのため、対象地域外の発表・更新でも条件が合えば鳴る可能性があります。

## 音と振動・表示

自動通知時は短い振動と通知音を1回出し、画面下に「新規通報通知」を表示します。通知音の設定は消音・小・中・大の4段階です。**消音でも振動は残り**、表示は「新規通報・消音（振動）」になります。A/B同時長押しによる「手動通知テスト」は受信通報とは別の操作です。

「L1S受信中」や受信B・L1S件数の増加だけでは自動通知しません。検証ログへの記録件数も通知件数ではありません。画面に通報が表示された場合でも、上記の条件に合わなければ音・振動は出ません。

実装箇所: `processSfrbx`、`ageForDcr`、`ageForDcx`、`considerAutomaticAlert`、`rememberAlert`、`startAutomaticCue`（`firmware/stopwatch-standalone/src/main.cpp`）。
